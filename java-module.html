Java Fundamentals: Interactive Concept Module

A short lesson on Java control flow, sequenced with Bloom's Taxonomy — recall a term, see how the pieces connect, then apply it in a quiz. Click any underlined term for a quick definition.

Learning objective: By the end of this module, the learner can identify Java's core control-flow structures and predict how a simple program will execute.
Step 1 — Recall

Key terms

Every Java program is a sequence of instructions run inside a methodA named block of code that performs a task. Every Java program starts running from a method called main.. Programs make decisions using a conditionalA statement — like if / else — that runs different code depending on whether something is true or false., and repeat work using a loopA block that repeats a set of instructions, such as for or while, until a condition is met.. A variableA named container that stores a value, such as a number or piece of text, which can change while the program runs. holds the values these decisions and loops act on.

Step 2 — See it in code

A loop and a conditional together

This short program checks each number from 1 to 5 and prints whether it's even or odd — a loop doing the repeating, a conditional doing the deciding.

// prints even/odd for numbers 1 to 5
for (int i = 1; i <= 5; i++) {
    if (i % 2 == 0) {
        System.out.println(i + " is even");
    } else {
        System.out.println(i + " is odd");
    }
}
